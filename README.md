## 🔧 Description (English)

**Osama Toolkit** combines powerful Wi-Fi auditing tools (Airgeddon, Wifite2, and Fluxion) into a single, easy-to-use script.

### ✔ Features:
- Auto-clones and installs missing tools
- Simple text-based menu
- One-click access to each tool

### 🖥️ Requirements:
- Linux OS (Kali Linux recommended)
- Python 3, git, bash
- Internet connection (only needed the first time)
